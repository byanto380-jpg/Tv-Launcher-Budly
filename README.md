# SmartTV-Launcher (Nusantara TV Launcher)

Launcher Android TV Box modern berbasis Kotlin & Jetpack Compose for TV, bebas iklan, dengan build APK otomatis via GitHub Actions.

## Fitur Utama
- **Jadwal Sholat & Kalender Hijriah** (Aladhan API + notifikasi pengingat waktu sholat)
- **Perkiraan & Status Cuaca** (Open-Meteo API)
- **Jadwal Pertandingan Sepak Bola** dengan pilihan liga (Premier League, La Liga, Serie A, Bundesliga, Ligue 1, UCL)
- **Widget Playlist IPTV (.M3U)** via URL atau file lokal
- **Live Wallpaper & Screensaver Internal (`DreamService`)**
- **Rak Aplikasi dengan Ikon Asli & Pencarian Cepat**

## Cara Build APK di GitHub
1. Unggah seluruh isi folder ini ke repositori GitHub Anda (branch `main`).
2. Buka tab **Actions** > **Build Android TV Launcher APK** > **Run workflow**.
3. Unduh hasil build pada bagian **Artifacts** (`SmartTV-Launcher-APK.zip`).
